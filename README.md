# 🛒 Simple E-commerce

Este é um projeto básico de e-commerce desenvolvido com HTML, CSS e JavaScript. O objetivo foi criar uma interface inicial simples e funcional, ideal para aprender e aplicar conceitos de desenvolvimento web.

# 📋 Funcionalidades

Exibição de produtos de forma organizada.
Utilização de arrays para armazenar todos os produtos, facilitando a adição ou remoção de itens para venda.
Design responsivo com CSS, garantindo boa experiência em diferentes dispositivos.
Código limpo e modular com JavaScript.

# 🛠️ Tecnologias Utilizadas

HTML: Estrutura da página.
CSS: Estilização e design responsivo.
JavaScript: Manipulação de elementos e dados dos produtos.
🗂️ Estrutura do Projeto
index.html: Página inicial com a exibição dos produtos.
style.css: Arquivo de estilos para o layout e design.
app.js: Script que armazena os produtos em um array e manipula a interface.

# 🔍 Aprendizado

Durante o desenvolvimento, explorei conceitos importantes, como:

Uso de arrays para centralizar os dados dos produtos, facilitando futuras modificações ou expansões no catálogo.
Manipulação do DOM com JavaScript para exibir dinamicamente os produtos na tela.
Organização de arquivos e separação de responsabilidades no código.
